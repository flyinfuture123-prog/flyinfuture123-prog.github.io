怎麼用這個網站

作答與計分

  • 單選題答對 5 分；多選題比照學測：全對 5 分、錯 1 個選項 3 分、錯 2 個選項 1 分、錯 3 個以上 0 分。
  • 選填題要把每一格數字都填對才給分，負號請填在第一格。混合題的非選擇題由你對照參考答案與評分要點自評 0 到 5 分。
  • 作答紀錄只存在你自己的瀏覽器裡，換裝置不會同步；按右上角「清除紀錄」可以重來一次。

核心意義動畫

  • 每一題的右側（手機版在下方）都有一段專屬動畫，分成幾個步驟，可以自動播放、逐步點按，或拖曳進度條回看。
  • 動畫演的不是計算過程，而是「這題到底在考什麼觀念」：例如絕對值就是距離、行列式就是面積倍率、取對數就是把乘法變加法。
  • 若你的系統開啟了「減少動態效果」，動畫不會自動播放，改用逐步點按。

每週更新與 PDF

  • 每週一清晨由 GitHub Actions 依當週週次為種子重新組卷：20 個題型固定，但數字、情境、正誤選項都會重新抽，答案由程式計算與驗證。
  • 換卷時上一週的卷子會封存到「歷屆預測卷」，可切換回去線上作答；同時產生兩種 PDF：學用版只有題目與答案卡，教用版加上答案總表、詳解、核心意義、命題說明與每題動畫連結。
  • 各週的作答紀錄分開保存在瀏覽器裡，互不影響。

命題依據

  • 範圍：108 課綱普通型高中數學 1、數學 2、數學 3A、數學 4A，與學測數學 A 考試範圍一致。
  • 題型與配分比照近年學測數A：第壹部分選擇（填）題 85 分、第貳部分混合題或非選擇題 15 分。
  • 各單元的預測熱度是編者依課綱份量與近年學測數A的出題習慣估計的，僅供安排複習順序參考。
